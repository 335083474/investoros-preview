# InvestorOS Preview

Static, interactive design preview for InvestorOS Desktop.

All portfolio values, records, versions, and statuses are synthetic examples. This preview does not connect to a real database, desktop AI host, broker, or trading account. It does not execute trades or confirm official records.

No analytics, remote API, remote font, or browser persistent storage is used. Demo draft inputs stay in page memory and disappear on reload. Please enter fictional data only.

This repository contains only the generated public preview artifact. It is not the InvestorOS core source repository.
